## TL;DR
An 82-minute free beginner Revit course that builds one small residential building from a blank file to a finished architectural model: interface/navigation, project setup, walls (ground + upper floor), stairs, floors, railings, balcony wall, doors/windows, curtain walls, roof, family placement, and finishing touches. Purely architectural modeling in Revit's UI — no MEP, no structural calculation, no compliance content.

## Key Claims / Techniques
Course structure (by timestamp), all Revit-UI operations:
- **Interface and Navigation** (1:01) — basic Revit interface orientation and selection tools.
- **Project setup** (12:29) — starting the project, initial levels/template configuration.
- **Ground floor walls** (17:53) and **Upper floor exterior walls** (24:51) — placing wall types by floor.
- **Creating stairs** (30:08) and **Creating floors** (32:57).
- **Upper interior walls** (38:47), **Railing** (42:21), **Balcony wall** (45:32).
- **Doors and windows** (49:39), **Curtain walls** (55:01), **Roof** (58:28), **Curtain wall doors** (1:04:58).
- **Placing families** (1:09:30) — furniture/fixture family instances.
- **Finishing touches** (1:18:45) — final cleanup pass before the model is considered complete.
- Positioned as the first project in the creator's longer paid "beginner to intermediate" course; free project files are offered via an external site.
